# Splunk app screenshots: Teleport Lab

Every dashboard in the `teleport_lab` Splunk app, captured end to end. Time range: last 15 days. Data source: both the live `teleport` index and the synthetic `teleport_demo` index (demo data is labelled synthetic). No credentials or tokens appear in these images.

Each page is tall, so it is shown as several shots, top to bottom (`-a`, `-b`, ...).
